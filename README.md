## 📖 About the Repository
This repository serves as an archive for the solutions and code developed during the **MC102 - Algorithms and Computer Programming** course at the State University of Campinas (Unicamp).

The main focus is on structured programming logic using **Python**, covering everything from basic input/output to complex data manipulation.

---

## 🏗️ Repository Structure
The exercises are organized mainly within the `Beecrowd` folder, corresponding to the problem sets assigned during the semester.

```text
MC102-Unicamp/
│
├── Beecrowd/           # Solutions for Beecrowd (URI) problems
│   ├── 1/              # List 1 - Basic Variables & Input/Output

│   ├── 3/              # List 3 - Loops (while/for)
│   ├── ...
